## 3. 본문

### 3.1 색상 토큰

| 토큰명 | 본문 | HEX | 활용 영역 |
|--------|------|-----|---------|
| `color-primary` | 주요 영역 | `#xxxxxx` | 버튼·헤더·강조 |
| `color-secondary` | 보조 영역 | `#xxxxxx` | 보조 버튼 |
| `color-success` | 성공 영역 | `#xxxxxx` | 알림·확인 |
| `color-warning` | 경고 영역 | `#xxxxxx` | 경고·주의 |
| `color-error` | 오류 영역 | `#xxxxxx` | 오류·차단 |
| `color-text-primary` | 본문 영역 | `#xxxxxx` | 본문·제목 |
| `color-text-secondary` | 보조 본문 | `#xxxxxx` | 부가 정보 |
| `color-bg-primary` | 배경 영역 | `#xxxxxx` | 본문 배경 |
| `color-bg-secondary` | 보조 배경 | `#xxxxxx` | 카드·패널 |
| `color-border` | 경계 영역 | `#xxxxxx` | 입력·구분선 |

### 3.2 타이포 토큰

| 토큰명 | font-family | font-size | font-weight | line-height | 활용 영역 |
|--------|-------------|-----------|-------------|-------------|---------|
| `typo-display-1` | (font) | 32px | 700 | 1.4 | 화면 제목 |
| `typo-heading-1` | (font) | 24px | 700 | 1.4 | 섹션 제목 |
| `typo-heading-2` | (font) | 20px | 600 | 1.4 | 하위 섹션 |
| `typo-body-1` | (font) | 16px | 400 | 1.6 | 본문 |
| `typo-body-2` | (font) | 14px | 400 | 1.6 | 부가 본문 |
| `typo-caption` | (font) | 12px | 400 | 1.6 | 캡션·주석 |

### 3.3 간격 토큰

| 토큰명 | 본문 | px |
|--------|------|-----|
| `space-xs` | 극소 영역 | 4px |
| `space-sm` | 소 영역 | 8px |
| `space-md` | 중 영역 | 16px |
| `space-lg` | 대 영역 | 24px |
| `space-xl` | 극대 영역 | 32px |
| `space-2xl` | 초대 영역 | 48px |

### 3.4 컴포넌트 토큰

| 컴포넌트 | 변형 | 토큰 영역 |
|---------|------|---------|
| 버튼 (Primary) | default / hover / disabled | `color-primary` + `space-md` + `typo-body-1` |
| 버튼 (Secondary) | default / hover / disabled | `color-secondary` + `space-md` + `typo-body-1` |
| 입력 필드 | default / focus / error | `color-bg-primary` + `color-border` + `typo-body-1` |
| 카드 | default / hover | `color-bg-secondary` + `space-lg` |
| 알림 | success / warning / error | `color-success` / `color-warning` / `color-error` |
