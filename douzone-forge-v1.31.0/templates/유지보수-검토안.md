| 축 | 본문 | 검증 영역 |

| git 커밋 | (PRJ-NNNN/TASK-CODE 프리픽스) | 브랜치 단계 + 머지 영역 |

## 4. 합격 기준 (AC, Acceptance Criteria, 합격 기준)

| # | 합격 기준 | 검증 방법 |
|---|---------|---------|
| AC-1 | 수용여부 판단 영역 종착 | 검토안 매트릭스 검증 |
| AC-2 | JIRA 이슈 상태 영역 동기화 | JIRA 검증 + 검토안 인덱스 |
| AC-3 | 3-way 크로스 체크 정합 | `/dz-triage-status` 출력 |
| AC-4 | 진행상태 매트릭스 종착 (처리완료 또는 기각) | 수동 전이 (`/dz-triage-close`) |
