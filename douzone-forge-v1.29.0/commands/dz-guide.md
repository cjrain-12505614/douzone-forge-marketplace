# /dz-guide — 다음 한 수 안내

**현황 수치를 나열하지 않는다.** 이 커맨드의 산출은 「지금 이어서 할 일 1~2개 + 어느 커맨드로 갈지」다.
숫자·표·진행률은 `/dz-status`(4축 현황)와 `/dz-projects`(포트폴리오) 영역이므로 중복하지 않는다.

## 영역 경계 (겹치지 않게)

| 커맨드 | 무엇에 답하나 |
|---|---|
| **`/dz-guide`** (본 커맨드) | **"이제 뭐 하지?"** — 다음 한 수 + 라우팅 |
| `/dz-start-session` | "이어서 하자" — 세션 복원 프로토콜 실행 |
| `/dz-status` | "지금 전체 어디까지?" — PRJ·작업항목·학습·사이클 4축 수치 |
| `/dz-projects` | "프로젝트 현황?" — 포트폴리오 대시보드 |

→ 사용자가 수치를 원하면 안내만 하고 그 커맨드로 넘긴다. 여기서 다시 세지 않는다.

## 실행 절차

### 1. 진입점 읽기 — `CLAUDE.md` 「세션 시작 시 체크리스트」 순서 그대로

워크스페이스 정본은 `CLAUDE.md`(forge)의 해당 절이다. **절 번호가 아니라 제목으로 찾는다** — forge CLAUDE.md에는 번호 절 체계가 없다.

| 순 | 읽을 것 | 무엇을 얻나 |
|---|---|---|
| 0 | `_개인/sessions/{대상}/_current.md`(forge) | 직전 진행·미결·재개 방법 |
| 1 | `프로젝트/_dashboard.md`(forge) | 진행 중 PRJ와 그 상태 |
| 2 | `Amaranth10/INDEX.md`(forge) | 작업 대상 모듈·기능 위치 |
| 3 | 모듈 `module-overview.md` → `문서/INDEX.md` → `context/{GNB}/_overview.md` → `history/_timeline.md` | 그 모듈 맥락 |

⛔ **세션 폴더 이름을 모듈명으로 추측하지 않는다.** `_개인/sessions/` 는 「모듈 **또는 작업**」 단위이고, 실측(2026-08-13) 폴더 **120개 중 모듈명과 일치하는 것은 5개**뿐이다(CRM·게시판(BOARD)·법무관리(LTE)·업무관리(KISS)·통합연락처(AB)). 나머지 115개는 작업 이름이다.

```bash
# 최근 손댄 세션부터 본다 (이름을 모를 때)
ls -1t _개인/sessions/ | head -10
find _개인/sessions -name "_current.md" -maxdepth 2 -exec ls -lt {} + 2>/dev/null | head -5
```

### 2. 상태 판정 → 안내

| 상태 | 판정 근거 | 안내 |
|---|---|---|
| **이어갈 세션 있음** | `_current.md` 의 미완 체크·「남은 작업」 | 그 항목 1~2개를 그대로 제시 → `/dz-start-session` |
| **진행 중 PRJ 있음** | `_dashboard.md` 의 진행 상태 행 | 가장 최근 갱신 PRJ의 다음 TASK → `/dz-status`(수치) 또는 `/dz-update-project` |
| **미결 결정 있음** | 해당 PRJ `06_의사결정/` 또는 `_current.md` 의 `_(확인 필요 …)_` | **결정을 먼저 받으라고 안내** → `/dz-decision` |
| **막 시작** | 세션 폴더도 PRJ도 없음 | 모듈 초기화 또는 개인 영역 정착 → `/dz-init-project` · `/dz-personal-init` |
| **오래 중단** | `_current.md` 갱신일이 오래됨 | 며칠 전인지 말하고 이어갈지 물음 → `/dz-resume-session` |

### 3. 라우팅 — 커맨드 2~3개만

전체 목록을 뿌리지 않는다. 지금 상태에 맞는 것만 고른다. 전건 레퍼런스는 `참고자료/사용자가이드/md/F-레퍼런스.md`(forge)다.

## 산출 형식

```markdown
## 지금 할 차례

1. {구체 항목} — {근거: 어느 파일의 무엇을 보고 그렇게 판단했는지}
2. {구체 항목}

**막고 있는 것**: {미결 결정이 있으면 · 없으면 생략}

→ `{커맨드}` · `{커맨드}`
```

## 주의

- **근거 없이 안내하지 않는다.** 각 항목에 "어느 파일의 무엇을 보고"를 붙인다.
- 진행률·건수는 세지 않는다(§영역 경계).
- `_개인/` 은 본인 로컬 전용이라 다른 사용자에게 없을 수 있다 — 없으면 없다고 말하고 1번(PRJ)부터 본다.
